# BunkIQ 😴

> **How many classes can I still skip?**
> A quirky, accurate attendance calculator for students to calculate their attendance threshold and know how many classes they can bunk safely (or how many consecutive classes they need to attend to recover).

## 🚀 Live Demo
Deployable seamlessly on [Vercel](https://vercel.com) & [GitHub Pages](https://pages.github.com).

## 🛠 Features
- **Smart Attendance Calculation**: Computes either the bunk budget (how many classes you can skip) or the recovery streak (how many consecutive classes you must attend).
- **Custom Target Attendance**: Defaults to 75% or whatever your university requires.
- **Humorous Disclaimers & T&Cs**: Humorous university life disclaimers.
- **Zero Dependencies**: Pure HTML, CSS, and vanilla JavaScript.

## 🌐 Deploy to Vercel
1. Push this repository to GitHub.
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Import your GitHub repository.
4. Click **Deploy** (No build settings needed, it's a static site).
